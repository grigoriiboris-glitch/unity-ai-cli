## Ownership

### Action Layer — Coplay MCP
Coplay MCP is the only Unity Editor transport. It owns scene and GameObject CRUD, component operations, scripts/assets/prefabs, Editor state, console reading, menu execution and Unity Test Runner calls.

unity-ai-cli does not duplicate these tools and does not host an MCP server.

### Verification Layer — Node.js CLI
The CLI operates on the repository filesystem:
- logs.mjs reads only a bounded tail of Editor.log, groups repeated errors by normalized stack fingerprint and optionally includes ±5 source lines.
- db.mjs stores diagnostic fingerprints, occurrences and task correlations in local SQLite.
- visual-diff.mjs uses sharp + pixelmatch for image comparison and bounded frame selection.
- verify.mjs combines log results with the latest Unity JSON report.
- checkpoint.mjs refuses Git snapshots unless the C# save-state file confirms that every open scene and asset is saved.

Node.js >=24.15.0 is required for the built-in node:sqlite API.

### Unity UPM package — C#
Checks that require live engine state stay in the Editor/Runtime package. The Editor bridge exposes menu items and public methods; it writes JSON files to .ai/artifacts/. It does not open sockets, HTTP listeners or register another MCP server.

## File contract

- .ai/artifacts/editor-save-state.json — generated by Tools/AI Verification/Save Scene and Assets. Includes status, savedAt, scenesSaved, assetsSaved, unsavedSceneCount and scene paths.
- .ai/artifacts/verification-report.json — generated by Tools/AI Verification/Run Selected Checks. Includes status, generation time, selected-object count, suites and anomalies.
- .ai/diagnostics/diagnostics.sqlite3 — local diagnostic index; raw Editor.log content is never copied into SQLite.
- .ai/checkpoints/ — local metadata describing annotated Git checkpoint tags.

## MCP-to-C# invocation

Use Coplay MCP's existing execute_menu_item tool:
- Tools/AI Verification/Save Scene and Assets
- Tools/AI Verification/Run Selected Checks

Alternatively, use Coplay's existing execute_code tool to call the public static method:
    return UnityAI.Verification.Editor.VerificationReportExporter.RunSelectedChecks();

No custom IPC channel is required. The CLI reads the files exported by Unity after the MCP call returns.

## Execution loop

1. Create a Git task branch and inspect the target through Coplay MCP.
2. Save and checkpoint before destructive edits.
3. Apply changes through Coplay MCP.
4. Enter Play Mode when UI pixel bounds need checking.
5. Run selected checks through Coplay MCP.
6. Run unity-ai verify --suite logs,physics,ui.
7. Repair failures through Coplay MCP and repeat.
8. Run relevant Unity tests; create a final checkpoint only after a successful Editor save.
